# Parts list

What a working Lorikeet setup needs. Prices are rough ranges as of late 2026, so check before buying. When you buy something, write the exact model and link in the table, so the other teammate can match it.

| Part | Need | What to look for | Rough price | Have? / exact model |
| --- | --- | --- | --- | --- |
| Projector | Required | HDMI input; 1280×720 or better; 2,000+ lumens for a dim room; short-throw if the play surface is close; manual keystone | $80–300 | |
| USB webcam | Required | 1080p at 30 fps; **manual exposure/white-balance lock** (avoids colour drift); a wide field of view (78°+) to see the whole projection | $25–70 | Ryan: has an external USB webcam |
| Webcam mount | Required | Small tripod or clamp arm, so the camera sits near the projector lens and stays put between sessions | $15–30 | |
| Sticky notes | Required | 3×3 in, **neon** colours (yellow, pink, green, blue) for high saturation; super-sticky for walls | $10–15 per multipack | |
| USB-C → HDMI adapter | Usually | For MacBooks without an HDMI port; supports 1080p60 | $10–25 | |
| HDMI cable | Usually | Long enough to reach from the laptop to the projector (3–5 m) | $8–15 | |
| Play surface | Optional | A matte white wall or a sheet of white foam board; avoid glossy surfaces (hot-spots blind the camera) | $0–15 | |
| Blackout or dim room | Optional | Not a purchase, but the biggest single quality win | $0 | |

## Notes

- A laptop's built-in camera works for a first test, but it faces the user, not the wall, and can't lock exposure. Plan on a USB webcam.
- iPhones can show up as a camera (Continuity Camera). Handy for a test, but it grabs camera index 0 when nearby.
- Test the projector and camera together in the room you'll demo in, before the demo. Lighting changes everything (ADR 0006).
