# Lorikeet - Projector + CV for physical interaction with games

## Abstract
Lorikeet is an application that creates an interface to use projectors as a way to create physical play surfaces for video games. **This is done through a video feed that is processed with computer vision libraries and then output as shapes and objects that can then be used as various inputs for games and other applications.** With Lorikeet, our games include ones where post it notes can be used as hard bodied surfaces for a puzzle game, and one where users can use post it notes as inputs for a tower-defense game.

Lorikeet's interface has two options:
1. Inputs are given as hard bodied objects in a space
  * This allows for games that require physics (like platformers or puzzles) to use the inputs as their environments.
2. Inputs are given as selections with space
  * This allows for user to essentially almost treat the projector screen as a large trackpad and have their inputs be treated as selections of a mouse or input of a keyboard. This could include strategy, planning, or tower defense games.
